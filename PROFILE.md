# APIVerve

An agent-native API marketplace exposing 300+ (367+ enumerated) ready-made REST APIs behind a single API key with a uniform JSON envelope. Offers REST, an alpha GraphQL gateway, OpenAPI + Postman contracts, a self-hosted apis.json, an llms.txt, and a hosted remote MCP server that turns the whole catalog into agent tools.

## APIs

- **APIVerve REST API** — Single-key REST gateway to 300+ (367+ enumerated) APIs sharing a consistent request shape and status/error/data JSON envelope (JSON default; XML/YAML via format param). Authenticated with an x-api-key header (or Authorization: Bearer / x-jwt). (`https://api.apiverve.com/v1`)
- **APIVerve GraphQL API (alpha)** — Single GraphQL endpoint that fans out to multiple APIs in one request. Explicitly labeled alpha / not for production. (`https://api.apiverve.com/v1/graphql`)
- **APIVerve MCP Server** — Hosted remote MCP server (streamable HTTP) exposing every catalog endpoint as individual MCP tools with input/output schemas. Auth is negotiated: OAuth 2.0 by default or API key via x-api-key. New endpoints appear automatically. (`https://api.apiverve.com/v1/mcp`)

> Provider self-publishes an apis.json at https://apiverve.com/apis.json (spec 0.19) listing both the REST API and MCP server. The hosted MCP server at https://api.apiverve.com/v1/mcp is streamable HTTP and registered as com.apiverve/mcp-server; an installer (npx @apiverve/mcp-server), a stdio bridge Docker image (apiverve/mcp), and PyPI package (apiverve-mcp) exist as local aids but are not cataloged as MCPServer. OpenAPI at assets.apiverve.com/openapi.json and the llms.txt body could not be opened directly by the fetch tool (host/context restrictions) but both are confirmed via apis.json, GitHub, and well-known detection. No formal agent-skills package was found. SDKs available for Node.js, Python, .NET, Go.
